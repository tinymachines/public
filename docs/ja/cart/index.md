# 較正カートリッジ

私たち自身のカートリッジが一つ。どの画面も測られるために作られている:
コンソールからはスコープとグラバーとカメラを通して、模型からは同じデコーダを
通して、そのすべてを一つの道具が読む。このセクションには、計画、ROM を作って
基板に載せるまでの手引き、絵としての画面、そしてチップを待っている空のボードが
ある。ROM とそのマニフェストもここで配っている:
[cal.nes](/nes/cal.nes) と [cal.json](/nes/cal.json)。手引きにあるチェックサム
が名指しするのと同じバイト列だ。

| | |
|---|---|
| [較正カートリッジの計画](/ja/docs/cart/calibration-plan) | どの画面も、実機と模型から同じ読み取り器で測られるために作られたカートリッジが一つ。各フレームが自分の名を名乗る。色、解像度、フィルタ、そしてパッド。 |
| [較正カートリッジを作る](/ja/docs/cart/build-the-cal-cart) | 自分の名を名乗るフレームという着想から、60 行のアセンブラで書いたカートリッジを経て、模型に載った ROM、そのチェックサム、そしてコンソールに差したカートリッジまで。 |
| [較正画面](/ja/docs/cart/calibration-screens) | 私たち自身のデコーダが見たカートリッジの画面、各フレームに名を付ける帯、そして各画面が何のためにあるか。カートがコンソールに入れば、グラバーのフレームもそこに並ぶ。 |
| [空のボードとプログラマ](/ja/docs/cart/cart-blanks) | 撮って読んだ: どの基板が較正 ROM の二つのチップを取るのか、EPROM アダプタは何のためにあるのか、そしてチップが届くまで分からないままのもの。 |
