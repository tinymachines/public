# 信号経路がリファレンスから離れる箇所

M5 の統合 (引き継ぎ仕様の 8 節): このパイプラインが自分のオラクルや
出典と意図して異なる箇所すべてと、それぞれがどこで測られたか。ここに
あるものは何一つ許容の内側に隠されていない。どれにも名前があり、大き
さがあり、在り処がある。

## blargg の nes_ntsc 0.2.2 から (docs/m1-report.md で実測)

| ダイバージェンス | DC での大きさ | 誰の選択か |
|---|---|---|
| レベル表: 彼の小数二桁の正規化レベル 対 実測の電圧 | 最大 5.48 カウント (基本色) | 彼の丸め |
| エンファシス: 彼の YIQ 空間での近似 対 実測の減衰した行 | 最大 45.81 カウント | 彼の近似 |
| クロマ: 基本波だけのフェーザ 対 実物の矩形波 (高調波) | こちらのルマは高調波をリプルとして運ぶ。彼のものは運べない | 物理 対 カーネル |
| デコーダ: -15 度回した彼の古典的 YIQ 行列 + 二次のガンマ 対 こちらの SMPTE UV + 2.2 | パイプライン全体の掃引で平均 23.0、最悪 68.9 カウント | どちらも正当。サイトはこちらを見せ、そう述べる |
| フィルタ: 彼の DSF-sinc のルマ + ガウシアンのクロマのカーネル 対 こちらの窓関数付き sinc | 行平均で 5.7 (帯) から 18.0 (縞) カウント | 書き下ろしの設計が違う |
| 二つのパイプライン間の、クロマ 対 ルマの遅延のずれ | 数標本。どの単一のリサンプラのオフセットも、すべての計器をゼロにはしない | 彼のカーネルは設計上非対称 |

## SMPTE ST 170M-2004 から (符号化器モジュールの文書に記録)

- 立ち上がり時間 (140/300 ns、表 2) は整形していない: 矩形の包絡線。
- 垂直同期は行の粒度: フレームの行 4..7 と 266..269 にだけブロードパルス
  を置き、半行の等化パルスは無い (復元はブロードの群を手がかりにする。
  規格の完全な構造は模型化していない)。
- SC-H 位相 (13.2) は調整していない。フレームの原点が自由パラメータだ。
- 再標本化してから帯域制限する順序 (帯域制限済みの内容では同一)。
- 1.3 MHz の等帯域 U/V は 7.2 項への準拠であって、ダイバージェンス
  **ではない**。I/Q の分割は、規格自身が置いた NTSC-1953 の継続注記だ。

## nesdev ページの模型から (docs/m1-report.md で実測)

- 微分位相歪み (DAC のインピーダンス効果を、あのページ自身が IIR で
  近似したもの。ルマの行あたり約 -2.5 から -5 度) は模型化していない。
  符号化器は理想的なエッジを出す。

## 内部で意図したもの (それぞれ在り処に記録)

- 中間表現は等帯域 YUV で、名前は `YuvFrame`。仕様は `YiqFrame` と
  言っていた (ntsc-decode のモジュール文書。7.2 項が YUV を主とする)。
- NES の 8/7 の画素アスペクトは CRT の段では適用しない (ntsc-crt の
  モジュール文書。シェルの整数倍スケールのキャンバス規則が勝つ)。
- CRT 模型のパラメータはすべて書き下ろしで、ブラウン管から実測した
  ものは一つも無い (CrtParams の文書、docs/m3-report.md)。
- キャプチャカードの模型はテスト装置であって、カードではない: 6.5 MHz
  の折り返し防止、一様雑音、線形のレート誤差だけ (ntsc-source-cap の
  文書)。実物の録音は M4 のゲートの、開いたままの半分として残る。
