# コンソールの弧のノート

私たちは節目を二度書き留める。コードの前に書く計画は、何をどれだけ近く
検査するかを述べる。作業の後に書く報告では、どの数値も、それを印字した
走行付きの実測だ。これらの文書はそれぞれのリポジトリにある。このページは
サイトがビルドされるたびにそれらを取り込み、コンソールのどの部分について
のものかで並べ替える。だから一箇所に集まっていて、写しはリポジトリの一つ
だけのままだ。報告が数字を出しているなら、それは走行が印字したものだ。
報告が何かを書き下ろしと呼んでいるなら、それは私たちがした選択で、そう札
を付けてある。報告には私たちの間で使う作業用の言葉が残っていて、
[報告書で使われる言葉](/ja/docs/words)がそれを説明する。較正カートリッジ
には[それ自身の節](/ja/docs/cart)がある。

## チップ

どのチップも話す規約、それから NES の二つのチップをスイッチのところで (2A03 は CPU と音、2C02 は絵のチップ)、そしてそこから作られた高速版。

| | |
|---|---|
| [チップが共有する規約](/ja/docs/nes/n0-report) | **N0 の報告。** ピンの表、ドットのフレーム、カートリッジのエッジを、依存の無い一つの小さなクレートにまとめ、記録済みのリファレンス走行に照らして検査した。 |
| [2A03 をスイッチのところで、リファレンスと厳密に一致](/ja/docs/nes/a0-report) | **A0 の報告。** NES の CPU と音のチップをトランジスタごとに模擬し、例外の一覧なしでリファレンスとビット単位で一致させた。 |
| [2A03 から出た最初の音](/ja/docs/nes/a3-report) | **A3 の報告。** プログラムの音をチップ自身の出力から読み取り、ミキサーはまだ実測していない主張として書き留めた。 |
| [高速 2A03 の計画](/ja/docs/nes/n3-plan) | **N3 の計画。** 10 進補正を切った 6502 の高速コアと、チップから実測した表としての音のユニット。 |
| [高速 2A03、作って検査した](/ja/docs/nes/n3-report) | **N3 の報告。** 高速チップをピンのところでトランジスタレベルのものに照らして検査し、音の表はチップから実測し、バスの停止はフレームごとに合わせた。 |
| [2C02 をスイッチのところで](/ja/docs/nes/p0-report) | **P0 の報告。** 絵のチップをトランジスタごとに模擬し、そのリファレンス走行を再生し、電源が入っているときにしか働かないトランジスタを見つけた。 |
| [2C02 の最初の絵](/ja/docs/nes/p1-report) | **P1 の報告。** 絵のチップを模擬したバス越しに駆動し、色の出力を表に一致させ、電源投入時に定まらないラッチを名指しした。 |
| [2C02 の難所](/ja/docs/nes/p2-report) | **P2 の報告。** スプライト 0、vblank の読み出し競合、OAM の破壊。どれも、リファレンスも答えを知らないまま走らせる小さなレジスタのプログラムで決着させた。 |
| [高速 2C02 の計画](/ja/docs/nes/p3-plan) | **P3 の計画。** 一度に一ドットずつ進む絵のチップを、トランジスタレベルのチップから実測した予定表で駆動する。 |
| [高速 2C02、チップとドット単位で一致](/ja/docs/nes/p3-report) | **P3 の報告。** 高速の絵のチップが、三つのテスト場面、レジスタの書き込み、そして描画を切ったときの絵で、トランジスタレベルのものと一致した。 |

## コンソール

二つのチップを一枚の基板に: 糊、テスト ROM を走らせる機械、そしてその絵、その音、それが遊ばれる窓。

| | |
|---|---|
| [メインボードの糊](/ja/docs/nes/n4-report) | **N4 の報告。** NES-001 基板のチップの間にある数点の部品。それぞれデータシートに照らして検査し、私たちが書いたものだと札を付けた。 |
| [二つのチップを一つのクロックで](/ja/docs/nes/n5-report) | **N5 の報告。** 走るコンソール: 二つの高速チップを一つのクロックに乗せ、その間のタイミングをトランジスタレベルのチップに照らして検査し、blargg のテスト ROM を端から端まで走らせた。 |
| [コンソールの絵の計画](/ja/docs/nes/n6-plan) | **N6 の計画。** 信号経路を通る絵と、捕捉したフレームをどう比べるか。許容は先に書き留めた。 |
| [コンソールの絵](/ja/docs/nes/n6-report) | **N6 の報告。** 信号経路を通る絵、描画を切ったときの画面をチップの上で実測したもの、そして採点した捕捉フレーム。数値は記録されたもので、当てはめたものではない。 |
| [コンソールの音の計画](/ja/docs/nes/n7-plan) | **N7 の計画。** 基板の音声段を通る音を、回路図から読み取る。 |
| [コンソールの音](/ja/docs/nes/n7-report) | **N7 の報告。** 基板の音声段を通る音、打ち消し合う blargg のミキサーのテスト ROM、そして彼が実機を録った音源をこちらのものと並べた。 |
| [コンソールの窓の計画](/ja/docs/nes/n8-plan) | **N8 の計画。** コンソールが遊ばれる窓、GPU の上の絵、歩調、そしてブラウザという二つ目の目標。 |

|---|---|

| [ベンチの道具が示したもの](/ja/docs/nes/bench-report) | 各道具が合成の走行で働き、それぞれに失敗しなければならない妨害の走行が付く。最初の問いには実機より先にチップが答え、模型はそれに合わせて変わった。 |

## ベンチを運動させる

二つのスタックを一段ずつ強く追い込む段取りと、それが自動化に教える言葉: 実機に合わせて調整される模型、パッドから学ばれるゲーム、そしてゲームのコードのレントゲン。

| | |
|---|---|
| [ベンチを運動させる](/ja/docs/nes/exercise) | 二つのスタックを、すべての流れに型を付けた一枚の論理図として。層ごとの方言、それぞれにゲートを持つ六段の段取り、そしてその上に載る三つの計画: 実機の上で実測される模型のつまみ、パッドから絵まで学ばれるゲーム、そしてコードの模様の百科事典の裏にあるレントゲン。 |
| [コードの模様の百科事典](/ja/docs/nes/encyclopedia) | レントゲンを足し合わせると何になるか: NES のコードの模様それぞれに、模型の上で実測した署名、ダイのページへの窓、そしてそれが教える仕組み。コードは出所が私たちのものであるカートリッジからだけ |
| [Super Mario Bros. を解剖する](/ja/docs/nes/mario-dissection) | 模型の上で分解した最初のゲーム: 割り込みの中のループ、走査線ごとのフレーム、ジャンプエンジンを通るルーチンの木、VRAM のパイプライン、そしてジャンプへ向かうパッドのバイト。形だけで、コードは決して出さない |
