## How a deploy goes

Deploy only on the owner's word, typed in your session. Another session
cannot relay it.

1. The tree must be clean, untracked files included. The deploy refuses
   otherwise, and the permission check refuses `--dirty`. If something you
   did not put there appears in the checkout, it is the owner's: ask, do
   not move or delete it.
2. If the commit moves the tinypeek pin, push tinypeek **first**, so GitHub
   has the commit `public` points at.
3. Message the bradleyio session (`port-bradley-tinymachines-style`) that a
   deploy is starting. It deploys too, and the first to start goes.
4. Run `scripts/deploy.sh` in the background and read its log. It builds,
   restarts, checks the worker stamp, provenance and the three subdomains,
   pushes, has the beta follow, and last crawls the namespace
   (`scripts/check-tm-links.py`, about 2,300 URIs).
5. Message the bradleyio session that it is clear again.

## Rules this work has paid for

These are in `CLAUDE.md` or in the session's memory already; they are here
because each one cost a round.

- **Live serves from this checkout.** Never run `next build`, a docs pull,
  or anything that writes `web/public` here outside the deploy. To build and
  test, use a throwaway sibling worktree (`git worktree add --detach
  ../public-tw HEAD`, copy the pretext submodule in, `cp -al
  web/node_modules`, `bun run build`, `next start` on a free port), then
  remove it. The play button's e2e test fails there because only the deploy
  builds the emulator bundle.
- **A test must fail without its fix.** Revert the fix, watch it go red.
- **A check that passes on nothing is not a check.** When a crawl or a
  check passes, break the thing it guards on purpose and watch it catch it.
- **A Japanese edit needs a stamp.** Change an English notebook page and its
  Japanese shadow together, then `bun scripts/check-ja-docs.mjs --stamp`
  in `web/`, then `python3 data/check-og-font.py` and `python3
  data/check-i18n.py --strict`.
- **Escapes in a tool command are decoded before it runs.** Build a `\u`
  escape from `chr(92)` if the file must keep it literally.
- **No em dashes, no host detail** in anything committed. `notes/` is served
  through the namespace, so it counts.
